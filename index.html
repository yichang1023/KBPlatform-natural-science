還沒有 API 金鑰?照這三步取得(只要有 Gmail 就能登入)
  1. 點下面的按鈕,用自己的 Gmail(Google 帳號)登入。
  2. 在頁面上按「建立 API 金鑰」(Create API key)。
  3. 複製那一長串金鑰,貼回上面的欄位,再按「測試並儲存金鑰」。
前往取得 Gemini API 金鑰(Google AI Studio)
金鑰等於密碼,請不要貼到公開的地方,也不要傳給別人。如果學校的 Google 帳號無法使用,請改用個人 Gmail。

* 上面驗證成功後,金鑰只存在這台電腦的瀏覽器(Local Storage)。要讓學生在家也能用,請用下面的「儲存到雲端」。

讓全班在家也能用 AI(儲存到雲端)

把上面的金鑰存到雲端後,學生不用自己設定;他們按 AI 功能時,由伺服器代為呼叫 Gemini,學生的瀏覽器看不到金鑰。需要先在 Vercel 設好「管理密碼」與「Firebase 服務帳戶」(見「AI金鑰雲端設定說明」)。
